Calculadoras de Potência Óptica FTTH

Ferramentas para simular e validar projetos de redes ópticas, ajudando a estimar o sinal que chegará ao cliente final.

Ir para Calculadora Desbalanceada Ir para Calculadora Balanceada

Rede Balanceada

Nesta arquitetura, a potência óptica da OLT é dividida igualmente entre os usuários. O cálculo soma todas as perdas fixas ao longo do caminho.

Fórmula:

Sinal Cliente = Sinal OLT - Perda Splitter 1 - Perda Splitter 2 - Perda Cabo - Perdas Conectores/Emendas

É ideal para áreas com densidade uniforme de assinantes.

Rede Desbalanceada (Barramento)

Utiliza splitters que dividem o sinal de forma desigual. Uma pequena parte do sinal é "derivada" para o cliente (drop), enquanto a maior parte continua (pass-through) para a próxima caixa.

Cálculo por CTO:

  • Sinal Cliente = Sinal Entrada - Perda Drop - Perda Splitter Interno
  • Sinal Saída = Sinal Entrada - Perda Passagem

O Sinal Saída de uma CTO se torna o Sinal Entrada da CTO seguinte. É uma arquitetura flexível, ótima para distribuição linear de clientes (ex: ao longo de uma rua).
